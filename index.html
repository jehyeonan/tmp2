팀별 CSV를 통합하고, 누락·형식 오류·중복 후보를 우선 확인한 뒤 하나의 결과 파일로 내려받습니다.

안전 기준
실제 개인정보, 민원 원문, 내부자료, 예산·계약 자료는 업로드하지 않습니다. 수업용 가상 CSV만 사용하세요.

파일을 추가하고 규칙을 적용하면, 검토가 필요한 행을 바로 확인할 수 있습니다.

1. CSV 파일 추가

필수 열: 팀명, 제출자, 부서명, 업무유형, 제목, 처리상태, 처리기한, 우선순위, 내용

2. 업로드 목록

3. 규칙 적용

처리상태·우선순위를 표준화하고, 기한·중복 후보를 점검합니다.

파일을 추가한 뒤 규칙 적용을 누르세요. API를 사용할 수 없으면 브라우저 내 fallback 규칙으로 처리합니다.

4. 결과 검토
